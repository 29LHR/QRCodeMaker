# QR Code Maker

A website that doesn't require logins or payments, just gives you a QR code.

## Running

- Requires Python 3.15 (uses Flask, PIL, qrcode libraries)
- Run src/qrcodemaker/\_\_init\_\_.py
- This will create a localhost website on http://127.0.0.1:5500

## Creating

- Put in the URL you would like to turn into a QR Code
- Press Create QR
- Right click the QR code and press _Save Image_
